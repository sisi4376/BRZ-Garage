# BRZ Garage 授时桥（HarmonyOS）

这是 Android 版 BRZ Garage 的轻量鸿蒙原生授时辅助应用。它通过 HarmonyOS PartnerAgent 将已配对的 BRZ 仪表注册给系统；仪表上电并被系统发现时，先给 Android 版 8 秒优先连接窗口，只有 Android 没有连接时才执行一次短暂授时。

## 设计边界

- Android 已连接时授时桥不介入。
- 兜底路径只连接仪表的专用写入特征 `0x000F`，写入一次当前 Unix 时间，收到响应后立即断开。
- 不读取行程、不订阅实时数据、不执行持续扫描，也不维持 GATT 连接。
- 专用特征不取得 Android 数据连接状态，不修改通知开关、历史游标、筛选规则、设置或 OTA 状态。
- 仪表连接 ELM327、采集 OBD 和写入本地行程的任务完全独立，不改变频率、速度或数据格式。
- 行程同步、固件更新、设置和记账仍只在 Android 版开发和维护；本应用不负责让 Android 兼容层进程常驻。

## 使用前提

- 手机系统需要支持 PartnerAgent（HarmonyOS API 23 或更高版本）。
- 仪表固件必须为 3.3.1 或更高版本，才能提供隔离的授时特征。
- 先在 Android 版 BRZ Garage 中绑定仪表并完成系统 LE 配对。
- 安装本 HAP 后打开一次，启用“仪表上电兜底授时”；成功注册后无需保持页面或应用运行。
- 2.1.2 起首次注册会优先识别系统已配对、已连接的仪表，避免 Android 已连接导致仪表不广播时一直查找。仅在系统列表中未找到仪表时，执行最多 30 秒的广播扫描。

## 构建

用 DevEco Studio 打开本目录并配置签名，构建 `entry` 模块。命令行构建产物位于 `entry/build/default/outputs/default/`。
