# Android 4.5.0 资产管理测试

2026-11-02，versionCode 160。安装包 `android_app/BRZ-Garage-v4.5.0-debug.apk`，覆盖安装保留数据。

精细版记账分为加油、固定开销、日常、资产。资产页显示跨年份的当前持有清单及登记成本，处置历史按所选年份筛选。固定开销仅保留保养/维修、保险、年审、证件手续。

“登记资产”录入名称、日期、成本和备注，不显示更多信息；免费获得可填 0。一次登记代表一件资产或一个整体套装。旧配件用品记录直接沿用，名称不足可补充，不重复计费。

“资产处置”选择出售或移除。出售金额自动计入一笔“配件出售”收入，在日常收入与账本汇总中查看；移除不产生收入。处置后的资产不再出现在持有清单。点击处置历史可编辑日期、金额、备注或撤销处置；撤销会恢复持有并删除关联收入。

数据：SQLite 6、ZIP v5，新增 asset_ref 关联稳定 transfer_id。重复处置在本地事务及数据包校验中阻止；已处置资产不能直接删除登记，须先撤销处置。处置日期不得早于登记，登记日期也不得改至处置之后。旧 v1–v4 包仍可导入；旧 App 不支持 v5，须升级。

验证：30 个迁移场景与关联保养/通知/资产规则、6 项记账回归、106 项鸿蒙运行时测试与 Android → Harmony → Android 数据往返通过。鸿蒙仅提供数据格式兼容，尚未对齐资产 UI；平台 UI 一致性基线检查保留差异，不自动刷新。未连接真机或模拟器，未进行安装后的视觉和交互验收。

精简版兼容：保留既有配件用品录入与可选附加字段方式，精细资产表单的必填名称仅适用于精细版。已验证精简编辑金额/备注后保留资产稳定标识，编辑出售收入后保留处置关联，且不重复计入收入。精简版记录列表中的处置收入可打开专用处置表单；删除该收入按撤销处置处理。
