## 最终查询顺序

| 位置 | 主查询 | 随后追加 |
|---|---|---|
| 0 | 转速 `01 0C` | 无 |
| 1 | 车速 `01 0D` | 无 |
| 2 | MAF `01 10` | 转速 |
| 3 | 发动机负荷 `01 04` | 车速 |
| 4 | 节气门 `01 11` | 转速 |
| 5 | 燃油系统状态 `01 03` | 车速 |
| 6 | 指令空燃比 `01 44` | 转速 |
| 7 | 下列七项轮转中的一项 | 车速 |

每轮转速和车速各 4 次，MAF、负荷、节气门、燃油状态、指令空燃比各有一次查询机会；燃油状态确认不支持后停止请求，但对应追加车速继续执行。删除原空挡位位置，没有主动挡位或原厂里程查询。

最后一个位置按“进气温度 `01 0F` → 水温 `01 05` → 油温 → 电压 `01 42` → 油箱液位 `01 2F` → 直接燃油流量 `01 5E` → 支持位 `01 40`”轮转，每轮只查一项，每项每七轮查询一次。ZD8 油温使用 `01 5C`，ZC6 使用 `21 01`；6MT 与 6AT 采集顺序一致。

取消燃油参数的 500 毫秒限制、温度和电压的固定 5 秒限制、油箱液位的 30 秒及连续无响应停查限制。七项轮转继续保留不支持／无响应的项目。ELM 初始化或重连后从进气温度重新轮转。

全部请求仍为串行请求／响应，实际刷新率取决于 ECU、适配器、蓝牙和超时耗时；每七轮不是每七秒。手机录制中的新调度标记为 `brz-8slot-v5`，全量扫描和历史录制回放规则保持不变。

## 油耗计算与兼容性

有效 `01 5E` 优先；过期或不可用时，使用 MAF／指令空燃比与原有断油估算。`01 40` 报告不支持 5E 时清除直接燃油流量缓存。5E 的轮转间隔超过数据有效期时，可能在 ECU 与 MAF 来源间切换。

固件仍约每 200 毫秒按真实时间差积分，数据有效期、缺样处理、现有 NVS 布局和行程存储格式不变。此次不重算旧行程；手机工具的统计仍是自身的采样估算，未完整复制固件的断油推断。原理和限制见[油耗计算说明](FUEL_CALCULATION.md)。
