# Android 4.5.2 资产完整事件历史

2026-11-02，versionCode 162。覆盖安装包：`android_app/BRZ-Garage-v4.5.2-debug.apk`。

持有清单与历史是不同的数据视图。持有清单只显示有效登记且没有有效处置的资产；历史保留所有登记、出售、移除及后续撤销事件，按年份查看。出售或移除不会删除登记；历史详情显示原日期、金额、备注及是否已撤销。

资产原记录不能直接编辑覆盖或物理删除。误录时查看原记录、追加撤销、再重新登记或处置：撤销出售/移除会恢复持有，撤销出售后该笔收入不再计入有效账目；撤销登记使资产不再持有且原购入金额不再计入有效支出。所有原事件仍可查看，撤销事件也单独保留。已处置资产须先撤销处置才能撤销登记。精简版也遵守相同的资产历史保护规则，其他普通账目仍照常编辑与删除。

当前库存和统计通过完整日志计算；取消发生在另一年时，原记录仍在原年份历史显示，并标注已撤销，计算不会重复计费。历史月份摘要显示有效净支出。原始金额在历史中保留，不作为有效金额重复计入。

备份升级到 v6，字段与 v5 一致但增加不可覆盖的 asset_cancel 语义；继续读取 v1–v5。工作区鸿蒙数据层保留所有事件、计算有效账目并阻止编辑/删除资产原事件，尚未对齐完整资产交互 UI。旧版本需升级后读取 v6。此前版本已经物理删除且没有备份的记录，无法从现有数据重建。

验证：31 个迁移及关联规则场景通过，其中资产测试保留原登记/出售/移除及 3 个撤销事件，库存和有效金额归零后所有 6 条历史仍在；原记录修改和物理删除被阻止，重复撤销被阻止；完整日志导出、恢复、重复导入均保留。6 项记账回归和 106 项鸿蒙运行时测试通过，Android → Harmony → Android 全数据往返通过。完整 UI 平台一致性检查仍提示已知 Android 功能差异，没有自动刷新基线。尚未进行真机视觉和交互验收。
