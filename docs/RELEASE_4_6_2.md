# BRZ Garage 4.6.2 Beta · 固件 4.1.2

本次把此前分散在本地副本与发布分支中的修改汇总到 `main`，恢复 4.6.1 快照遗漏的旧修复。Android 4.6.2（versionCode 167）、固件 4.1.2、Windows 烧录工具 r4；鸿蒙源码保持 0.6.0，内置固件资源更新，不附新 HAP。

## 对比范围

- 上一完整发布：`v4.6.1`，源码 `f32941b10801c947e9ee805d165b24dd0ad42404`，Android 4.6.1（166）、固件 4.1.1、烧录工具 r4。
- 本次：`v4.6.2`，发布标签对应 `main` 上的发布提交。两条历史正常合并，保留此前 `main` 的 `fcc277e29404e2a686f4be03d79a42be466f0be4`，不改写历史。
- 下方另列从上一轮 4.3.15（构建 157，实际打包源码 `fcc277e`，内置固件 4.0.8）到 4.6 系列的累计更新，补足先前 4.6.1 正文漏项。固件上一独立发布为 `firmware-v4.0.8`。这些累计功能多数已经在 4.6.1 中，本次保留，不宣称全部为 4.6.2 新增。

## 4.6.1 → 4.6.2 全部变化

- 恢复 Android 系统配对兼容：仅在支持的 API 版本调用新的 LE 配对重载，旧系统使用兼容入口，避免绑定时缺失方法异常。
- 恢复绑定完成回调去重，防止系统选择器和伴生关联重复触发保存；配对时暂停连接而非停止尚待进入前台的服务；服务创建及每次启动及时确认前台状态，扫描、自动重连和广播直连均遵守配对暂停，并保留超时恢复。
- 恢复蓝牙地址大小写规范化，兼容伴生设备管理返回的小写 MAC 和已有保存地址，覆盖升级后无需因地址格式重新绑定。
- 恢复本地异常记录：启动安装异常处理器，保留最近异常类型、代码堆栈和绑定步骤；反馈模板加入配对、唤醒及地址格式状态，不记录异常消息、完整蓝牙地址，不自动上传。
- 固件恢复 GNSS 一次性授时：支持已有串口及 G 版 I²C 探测实现；无模块退出，成功授时或手机已授时后结束接收任务；校验连续 RMC 时间，拒绝无效时间和定位。手机授时优先，时钟来源以原子状态发布，授时与行程记录互斥处理；TIME 指示使用有效时钟状态，保留手机连通颜色含义。G 版硬件仍需实机验证。
- Android 恢复 4.0.7、4.0.6 历史固件及回滚目录；保留已有 2.6.0 安全版入口。当前升级镜像换为 4.1.2，鸿蒙资源与之同步。历史回滚不含新里程及自动挡支持，不建议作为自动挡配置的常规升级路径。
- 重新生成完整 APK、OTA 镜像及 r4 烧录包，并更新 App 在线更新清单和主页下载版本；包内固件必须逐字节一致。
- 恢复独立固件发布跳过自动烧录包构建的条件；完整发布已有验证 ZIP 时继续跳过重复构建，保留原附件。
- 在 `AGENTS.md` 和 README 明确：`main` 始终承载正式发布最新版完整源码，发布前合并所有已接受修复并验证；Release 必须完整说明上一版至本版的全部更新。更新 GNSS、Android、鸿蒙及固件文档和回归测试。

## 4.3.15（157）→ 4.6 系列累计功能

### 记账、界面与到期提醒

- 增加精简／精细两种记账模式，复用同一份记录和稳定 ID；精细栏目为加油、固定开销、资产、日常。模式切换按栏目含义对应，保险、年审、证件、收入、资产子页可继续切换；分开保存滚动位置、年份、月份、收支状态和返回位置。
- 精细界面展示月度／年度账本、统计快捷入口、固定开销两列网格和日常收入／支出切换。收入独立分类，不混入支出构成；毛支出分加油、固定、资产、日常，净支出扣除收入并允许负值。精简模式保持原分类汇总，同时保证总支出、收入和净支出一致。
- 保养与维修分开录入、筛选和列示费用；维修内容不自动重置保养周期，只有选中的实际保养项目生效。显示最近剩余公里／月数及各自项目，缺日期或里程时不虚构周期；保留轮胎更换跟踪和快捷入口。
- 保险按车辆、规范化险种及实际保障起止日追踪，付款日期独立；交强险、商业险及其他险种分开。支持当前／待生效保单、连续续保合并提醒、空档或日期不足提示、续保预填、可清除日期及手工到期日，切换普通分类时恢复普通日期字段。
- 年检注册资料独立保存：初次注册日、适用规则、预计或已核实有效期；月份规范化为月末，车辆资料优先，旧费用日期回退。只有用户确认办结才参考下一周期，不因付款或时间经过自动推进；未绑定资料首次归属所选仪表且不覆盖已有车辆资料。
- 增加保险、年检、保养到期通知入口及权限管理，前台检查和约每 6 小时后台任务，重启后继续调度；按到期阶段、办理窗口、逾期去重，账目变化重算并移除旧周期。系统后台限制仍可能影响送达。
- 保留旧自定义分类和年审记录语义；专用栏目锁定分类，收入表单精简为日期、分类、金额、备注。切换模式或编辑普通字段不丢保险等附加信息。

### 资产与数据互通

- 增加资产登记、跨年份持有清单、成本及按年份的完整事件历史；旧配件用品记录沿用，免费获得可填零，一次登记代表一个资产或套装。
- 出售产生一笔关联收入，移除不产生收入，正常处置保留购入记录；防止重复处置、处置早于登记和有处置时直接删除登记，统计避免重复扣除售价。
- 资产原事件只读，误录使用“撤销并删除”并传播删除状态；删除处置恢复持有，清理关联旧撤销标记，旧撤销数据继续兼容。月度混合记录显示有效净支出，原金额与有效账目分开处理。
- 数据库增量升级，转移包写入 v6、继续读取 v1–v5，保存费用扩展字段、资产关联／撤销／删除状态、注册资料、提醒偏好和设备缓存；重复导入去重。旧版不保证能读取新版包，回退应用前应保留独立备份。
- 车辆展示补充变速箱信息；保持 2D／3D 偏好与现有资源、历史行程、当前驾驶日历／列表、加油和自定义区间同步。

### 固件与车型

- 新增 BRZ ZC6／ZD8 6AT 配置，关闭自动挡挡位查询、推算和显示，三连表同步自动挡状态；保留 6MT 配置。自动挡使用 ECU 燃油流量／MAF 路径，禁用未标定的断油估算；自动变速箱油单列，不虚设固定保养周期。
- 取消 OBD 1～2 km/h 归零，有效车速直接用于显示和里程积分；里程不再因燃油流量、MAF 或 RPM 缺失而暂停。有效耗油独立累计，怠速和低速均正常计油；低于 3 km/h 显示 L/h，达到 3 km/h 显示 L/100km。
- 不补造无效或陈旧数据、不重算历史缺失里程，保留 NVS 和 BLE 布局。异常燃油数据期间里程仍增加，缺失耗油不会被猜测补齐，相关平均油耗可能受缺数影响。
- 保留 4.0.8 的首次空配置默认 `OBDBLE` 行为，已有名称、绑定 MAC 及旧空名称的 `OBDII` 含义不迁移；普通升级不需清空 NVS。

### 鸿蒙与配套工具

- 鸿蒙源码从上一已发布 0.4.0／后续 0.4.1 源码推进至 0.6.0：对齐精简／精细记账、收支统计、固定开销、资产持有和事件历史、撤销删除、保养维修、保险日期和续保、年检注册资料及到期提醒；保留当前驾驶显示、归档交接和缓存标记。
- 鸿蒙加入通知授权、后台任务、周期去重、失败重试与点击记账入口，数据编解码和生产 Repository 支持 v6 与 Android 双向迁移；支持自动挡车型及保养过滤。本次仅交付源码和固件资源，未发布新版 HAP。
- 增加 Windows BLE ELM327 采集与 JSONL 回放工具源码、启动脚本及图形界面构建脚本；支持设备扫描、常用／全支持 PID／ZC6 查询范围、原始响应保存、实时曲线、倍速与循环回放。
- OBD Studio 统计增加瞬时油耗、有效样本平均油耗、燃油流量、积分里程、累计耗油、燃油余量、ECU 总里程、电压及停止后的摘要文件；标明 ECU／MAF 来源，过期或无效数据停止积分。回放按原始时间轴统计，不因倍速改变时间单位。此 Release 不附 Studio EXE，需按工具文档构建。
- Windows 一键烧录工具仍为 r4：保留 16 MB 分段备份、失败分段一次重读、身份及整备份校验、分区检查、保留 NVS／开机动画和写后校验；本次仅更换内置固件为 4.1.2。

## 附件、升级与兼容性

- Android：`BRZ-Garage-v4.6.2-debug.apk` 及 SHA-256，沿用原签名，覆盖安装保留数据；不要先卸载。App 升级不会自动完成仪表 OTA，连接后在固件更新页面升级到 4.1.2。
- 固件：`obd_brz_gauge.bin`、`latest.json`、SHA-256 和 `validation.json`。独立 BIN 是应用分区镜像，不能按整片镜像写到地址 0。
- 烧录：`BRZ-Garage-Flasher-v4.1.2-r4-Windows-x64.zip` 及 SHA-256。解压运行 `Start-Flasher.cmd`，按包内板型／串口确认流程操作；普通升级保留 NVS，先完成备份。三连表应全部升级后再选择自动挡。
- 新数据包为 v6，建议先导出备份再升级；旧版不能保证读取新字段。历史少计里程不会自动追回，自动挡、GNSS 和通知等设备行为仍有下述验证边界。
