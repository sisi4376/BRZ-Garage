# App 4.1.3：2D 显示开关与车漆调整

版本：4.1.3，versionCode 136。安装包 `android_app/BRZ-Garage-v4.1.3-debug.apk`。

## 设置

“设置 → 车辆 → 显示 3D 车辆”开关默认开启，选择保存在手机本地；车辆设置详情页也提供相同开关。

关闭后复用原有 `VehicleHeroView`，显示所选 ZD8 / ZC6 的原始 PNG 及自定义车牌，隐藏旋转、车色等 3D 操作栏。冷启动处于 2D 模式时不创建 WebView。已经加载的 3D 视图暂停并隐藏，重新开启时复用；在 2D 模式下的车型或车牌变更延迟到开启 3D 时传入。两种首页布局均使用这一逻辑。

## 渲染

- 中性大面积柔光环境代替多盏强方向光与狭窄反射条，减少孤立的白色高光。
- 使用 Three.js MIT 实现的 NeutralToneMapping 回移到本地 r160，以保留饱和车色；同步保留许可与来源。参考 [上游实现](https://github.com/mrdoob/three.js/blob/dev/src/renderers/shaders/ShaderChunk/tonemapping_pars_fragment.glsl.js)。
- 调整金属底漆与透明清漆的粗糙度，保留亮面/哑光区分。
- 分别修正轮胎、黑色轮毂与车窗的材质，避免纯黑、镜面橡胶和偏绿车窗。
- 使用柔和车底阴影，移除后侧可见的硬块状方向光阴影，减少阴影贴图开销。
- 本地 WebView 不使用旧脚本磁盘缓存；页面切换仍复用同一实例，不触发模型重载。

## 验证范围

- 浏览器预览检查 ZD8 / ZC6 原版 2D 图片、重新开启 3D、蓝/白/红车漆、亮面/哑光、前后视角与 390 px 布局。切换两次车型后资源读取为 2 次，切页不增加。
- 5 项相机回归测试、8 项车牌资产测试通过。
- Android 构建、APK 资源一致性、版本及原签名核验通过。内置固件保持 4.0.3。
- ADB 未连接设备，设置开关、WebView 生命周期及性能尚未经过真机操作验证；浏览器中的开关仅用于演示，不代表原生设置页截图。

3D 免费资产的造型细节和原 2D 宣传渲染图仍有差异，本次改善光照与材质，不声称完全匹配原图。
