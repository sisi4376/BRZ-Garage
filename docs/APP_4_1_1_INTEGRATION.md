# App 4.1.1 统一安装包

唯一当前测试包：`android_app/BRZ-Garage-v4.1.1-debug.apk`。App 版本 4.1.1，versionCode 134；内置仪表固件仍为 4.0.3。

## 两个 4.1.0 的来源与差异

两个并行打包任务共享工作区和版本号，分别输出了普通文件名与 `perf-monitor` 文件名，导致两个包都显示 4.1.0 / 133。

逐个比较 ZIP 内文件后确认：文件列表相同，Android 业务代码、清单和内置固件全部相同。只有以下两个文件不同，普通文件名的包更晚，包含完整的 3D 嵌入修正：

- `assets/vehicle-3d/app.html`：允许读取 GLB 内嵌的 blob 贴图。
- `assets/vehicle-3d/real-models.js`：内嵌视角、车牌特写与加载状态的最终修正。

## 整合内容

从当前统一源码重新构建 4.1.1，保留最新 ZD8/ZC6 3D 模型、换色、前后车牌、车牌高度修正，以及项目现有行程与 OBD 自检功能。内置 4.0.3 固件包含被动性能监测；未因 APK 统一重编或替换固件。

固件大小 2,117,168 字节，SHA-256：`9c03483bb1a29b3d474d297e8556398b9ffa28499194ac21d0d661df57df052e`。这与两个旧 APK 的内置固件一致。

两个旧 APK 和各自校验文件归档至 `android_app/archive/4.1.0-superseded/`，保留追溯但不再作为安装入口。今后打包不再以功能名产生同版本并列的安装包。

## 验证与安装

- 使用原有调试签名，版本号提升，可以覆盖任意一个旧 4.1.0；无需卸载。
- 编译、APK 版本/签名检查、12 个 3D 资源一致性及内置固件哈希校验通过；17 项嵌入固件/OTA 测试通过。
- 新包 SHA-256 见同目录的 `.apk.sha256` 文件。
- 3D 功能更新 App 即可。若仪表尚未升级到 4.0.3，需要监测功能时再从 App 的固件更新入口升级；已是 4.0.3 无需重复升级。
- 尚未进行真机与实车验证，也未发布到 GitHub。
