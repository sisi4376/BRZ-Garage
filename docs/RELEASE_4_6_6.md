## 仪表固件：六位置轮询

| 位置 | 主查询 | 随后追加 |
|---|---|---|
| 0 | MAF 进气流量 `01 10` | 转速 `01 0C` |
| 1 | 发动机负荷 `01 04` | 车速 `01 0D` |
| 2 | 节气门 `01 11` | 转速 |
| 3 | 燃油系统状态 `01 03` | 车速 |
| 4 | 指令空燃比 `01 44` | 转速 |
| 5 | 七项低频轮转中的一项 | 车速 |

- 原发布版 14 个位置缩为 6 个；独立转速、车速位置和空挡位位置删除。转速由每轮 11 次降为 3 次，车速由 4 次降为 3 次，全部通过追加查询分布在整轮。主查询都执行时共 12 条请求；燃油状态确认不支持后跳过该主查询，仍追加车速。
- 七项低频参数依次为：**进气温度 → 水温 → 油温 → 电压 → 油箱液位 `01 2F` → 直接燃油流量 `01 5E` → 支持位 `01 40`**。每轮只查一项，每项每七轮一次。ZD8 油温使用 `01 5C`，ZC6 使用 `21 01`；6MT 与 6AT 的采集顺序一致，AT 仍不显示挡位。
- 取消负荷、节气门、燃油状态、指令空燃比、MAF 的 500 毫秒限频；取消温度／电压的固定 5 秒限制、液位的 30 秒间隔及有限探测停查。七项低频轮转中的项目即使不支持或无响应也保留低频查询。ELM 初始化或重连后从进气温度重新轮转。
- `01 5E` 在本地中间测试阶段曾被取消，最终发布版保留在七项低频轮转中。有效 5E 优先用于油耗计算，过期或不可用时回退 MAF／指令空燃比及既有断油估算；`01 40` 报告不支持时清除直接燃油流量缓存。
- 积分仍约每 200 毫秒按真实时间差执行，数据有效期、缺样处理、NVS 数据布局和行程存储格式不变；不会重算旧行程。5E 的轮转间隔超过有效期时，可能在 ECU 与 MAF 来源间切换。
- 所有请求仍串行等待响应，减少请求数不等于保证某个刷新率。转速／车速每轮次数减少，实际刷新间隔未必更短；每七轮也不是每七秒。当前未提供本版仪表的实车轮询耗时或油耗准确度结论。

## BRZ Garage Android：连接、里程和通知

- 区分等待中的系统自动连接与已经启动的直接连接。重复的广播／系统唤醒不再关闭正在握手的直接连接，也不反复重置其超时；等待中的自动连接仍可被有效广播触发的直接连接替代。
- 蓝牙链路建立后，由服务发现阶段独占同步队列；确认授时服务和授时特征存在后才允许授时、读取、写入及后续同步。重复服务发现回调被忽略，断线时清除就绪状态。界面连接状态和设置／固件操作也检查服务是否就绪，减少“仪表服务不可用”和握手过程被抢占的问题。
- 首页里程在已保存／校准里程之上叠加尚未归档的当前驾驶距离；归档交接、删除后的归档标记及跨设备过滤用于防止重复累计。只改变首页实时展示，不重写校准基线或历史行程。
- 停车等待、已连接及驾驶中的前台通知补充车辆里程和预估续航；里程尊重显示开关，缺失数据仍显示未知。停车通知展开后明确标识最近同步数据；已连接时按仪表累计距离推进缓存摘要，异步刷新避免阻塞蓝牙握手，OTA 期间不抢占更新流程。
- 通知设置统一为“通知管理”：系统通知设置入口与年审、保险、保养三个独立发送开关。分项默认开启，保存在本机；关闭会停止对应可见／新提醒，重新开启保留发送历史，避免重复通知。系统通知权限仍是接收通知的前提。
- 移除分组／经典设置里的旧“等待仪表上电通知”快捷入口；连接、等待和低油量通知渠道仍存在，可以通过系统通知设置管理，不等于停用自动连接。
- 日常账目没有备注或详情时不再添加“未填写详细／未填写备注”占位行；保留实际填写的项目、往来方和备注。
- 内置本版 4.1.4-beta.3；新增 4.1.3、4.1.4-beta.1 手动回滚包，并保留原有 4.0.7、4.0.6、2.6.0 数据安全回滚包。正常更新只选择最新固件，回滚须手动选择和确认。

## 独立 OBD Studio Android：首次公开安装包

- Android 8.0+，独立包名 `com.brz.obdstudio`，可与 BRZ Garage 并存。支持 BLE 扫描／手填地址、按同样优先级连接 FFF0、18F0、FF12 类适配器。
- 提供 ZD8/ZC6 的 6MT、6AT 四车型仪表同款采集模式，最终采用本版六位置规则；另有全部标准 PID、常用 PID 和旧 ZC6 精简模式，可配置额外只读请求、时长和间隔。仪表同款模式使用固定调度，不接受额外命令。
- 实时显示转速、车速、水温、油温、油耗、里程、耗油、油量、总里程、电压，提供最近 60 秒转速曲线、原始响应与样本年龄、日志；ZC6 支持 `21 01` 完整多包油温解析。
- 原始请求、通知分包和完整响应按 JSONL schema 1 保存单调时间戳，可导入／导出、输出统计摘要并选择自动导出目录；停止时保存，文件尾部中断的不完整行可忽略。全部 PID 模式保持最近值，不因样本年龄清空；其他模式按有效期处理缺样，不能把保持值估算当作连续实测。
- 支持与电脑版 JSONL 互通，0.25～4 倍速、循环回放，手机可广播 FFF0 服务供实体仪表连接。回放按原始时间轴和 ECU 请求地址响应，支持 AT 指令行为、20 字节通知分包，未知请求返回 NO DATA，不注入静态假数据。
- 采集／回放期间使用前台服务，支持后台继续任务和通知中的停止入口；提供蓝牙／附近设备及必要系统权限处理，拒绝权限时给出提示。此能力尚未完成本次手机 BLE 现场验收。
- 统计沿用电脑版的 ECU 流量优先／MAF 汽油估算、速度与燃油共同有效区间规则；未完整复制固件的车型减速断油与挡位推断。
