# BRZ Garage 4.6.3 Beta

对比范围：上一公开 Release `v4.6.2` 至本次 `v4.6.3`。Android 4.6.2（167）→ 4.6.3（168）；鸿蒙源码 0.6.0 → 0.6.2（602），包含其间未公开发布的 0.6.1 更新。固件仍为 4.1.2，Windows 一键烧录仍为 4.1.2-r4，二者内容未改变。

## Android

- 新增默认启动页选择：车辆首页、驾驶足迹、用车记账、设置。冷启动采用设置，页面恢复和通知指定入口优先；新版分组设置与经典设置均有入口。
- 将未连接时的“等待仪表上电”通知拆为独立系统通知类别。在 App 设置中可进入该类别的系统开关，隐藏等待通知而保留自动连接。连接中、OTA 和低油量通知继续使用各自原有类别；系统可能仍显示前台服务运行指示。
- 设置行图标改为在 38 dp 色块中绘制 24 dp 图形，改善留白，不缩小行点击区域。

## 两端数据迁移

- 区分记录冲突、设置差异和仪表缓存差异，避免把配置变化统称为记录冲突。
- 加油历史修订跨版本时按整组选择且只统计一次，消除记录、修订号及配置项的重复计数；保留已有整组选择和导入前备份机制。
- 车辆登记 JSON 字段顺序不再导致误报；车辆投影值与时间戳一致时，不因原始缓存包表示不同而单独报告冲突。
- 导出格式升级至 v7，新增精简／精细记账模式及默认启动页偏好，两端可互相迁移；鸿蒙将记账模式与数据事务一同保存，重启后保留。旧包缺少模式时保留本机选择。
- 继续读取 v1–v6 数据包；v7 必须由支持该格式的 Android 4.6.3／鸿蒙 0.6.2 或后续兼容版本接收。旧 App 不支持读取 v7，请升级前另外保存旧格式备份。鸿蒙导出清单使用实际应用版本，不再写死 0.5.0。

## 鸿蒙源码 0.6.2（含 0.6.1 积累更新）

- 新增与 Android 对应的默认启动页设置，通知打开记账的指定入口仍优先；系统后台任务机制保持鸿蒙原生实现，没有新增长期等待通知。
- 补齐车辆注册／年检卡片：注册日、有效期、状态说明、编辑校准与“本次已办结”入口；注册状态单独按车辆登记计算。3D 车辆开关移入车辆资料组。
- 车型选择改为点击“保存并同步”后生效；亮度和自动加油识别阈值改为拖动选择后点击“应用”，不再松开滑块立即发送命令，未读取有效设置时禁用相应控制。
- 修复记账模式按钮占满横向空间挤压标题；统一标题字号与紧凑模式按钮、年份／月份选择入口，并补充栏目提示。
- 本次行程详情保留最高速度、最高转速及加减速极值字段，开始时间缺失时采用车辆时间减驾驶时长的回退；正确区分未采集极值。
- 补齐反馈页说明、概览、脱敏诊断展示及完整反馈模板；打开 GitHub 新问题页面预填模板，浏览器打开失败时复制模板供手动提交，不会自动发送问题。
- 新增有长度上限的本地 ArkTS 未处理异常记录，只保留代码位置和固定页面步骤，不保存异常消息、行程、完整设备地址或私人路径；不自动上传。它不等同于 Android 的全部系统退出诊断。
- 继承 0.6.1 的版本文案统一，设置、更新和反馈使用实际版本；补齐固件 4.0.6、4.0.7 回滚资源，保留 2.6.0 安全版；内置最终固件 4.1.2 与 Android 一致。
- 保留已有精简／精细记账、资产收支、保险／年检／保养提醒、当前驾驶和自动挡基础支持。本次未宣称所有界面和平台行为完全一致。

## 固件、工具与说明

- 固件及一键烧录工具无代码变化。已核对实际 4.1.2 镜像含 GNSS 卫星授时模块，配置启用；它不提供经纬度、轨迹或导航，本次没有新增定位功能。
- 一键烧录包仍内置同一份 4.1.2 镜像；已运行 4.1.2 的仪表无需因本次 App 更新重复烧录。
- 项目说明保留 1.75-G 为未来 GPS／定位扩展预留硬件的推荐理由，修正顶部和安装章节的下载入口；不再在主页放置助手内部工作约定或无关长文链接。

## 附件与升级

- `BRZ-Garage-v4.6.3-debug.apk` 及 SHA-256：沿用原 Android 签名，直接覆盖安装，勿先卸载；建议升级前导出数据备份。
- `BRZ-Garage-Flasher-v4.1.2-r4-Windows-x64.zip` 及 SHA-256：与上一发布相同；解压运行 `Start-Flasher.cmd`。普通升级保留 NVS，按烧录工具流程先备份。
- `obd_brz_gauge.bin`、其 SHA-256、`latest.json`、`validation.json`：仍对应固件 4.1.2。BIN 是应用分区镜像，不能作为整片镜像写入地址 0。
- 鸿蒙本次公开交付源码，不上传含设备授权信息的调试 HAP。

## 验证与限制

Android APK 与鸿蒙 ArkTS/HAP 构建通过；134 项鸿蒙宿主测试、33 个 Android 生产迁移／SQLite 场景通过，包含双向数据往返、记账模式保存恢复、冲突计数与诊断脱敏。附件的版本、签名、哈希及烧录包内置镜像已核对。

本次未进行手机安装、逐页视觉对比、系统通知开关真机验证、实际 BLE／OTA／后台通知送达验证、自动挡路试或 G 版 GNSS 实机验证。Beta 构建和宿主测试通过不代表这些设备验收已完成。
