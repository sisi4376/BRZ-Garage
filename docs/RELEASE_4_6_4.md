# BRZ Garage 4.6.4 Beta · 仪表启动页与四向朝向

对比范围：上一公开 Release `v4.6.3`（`45521843924d880217c75ef44b6f66b6a3b31db7`）至本次 `v4.6.4`。Android 4.6.3（168）→ 4.6.4（169）；仪表固件 4.1.2 → 4.1.3；鸿蒙源码 0.6.2（602）→ 0.6.3（603）；Windows 一键烧录包 4.1.2-r4 → 4.1.3-r4，烧录工具逻辑不变。包含上一 Release 后尚未发布的 OBD Studio 1.2、1.3、1.4 更新，提供最终 1.4 程序。

## Android 与鸿蒙

- 撤销上一版误加的 App 默认启动页设置。App 恢复原有首页启动行为，保留页面恢复及通知指定入口；旧 v7 备份中的 `default_start_tab` 仍可读取，但不再影响启动页面，不会因删除功能而拒绝已有备份。
- 在手机“仪表设置”中开放仪表默认启动页：温度、信息、图表、指针、挡位＋转速、车速、油量、行程历史、行程总览，共九个页面。
- 同处新增仪表默认朝向：以原安装方向为 0°，可选择顺时针 0°、90°、180°、270°。两项配置保存在仪表中，下次正常上电生效，不强制重启或跳转当前行程画面。
- 两端均先检查固件能力，再写入并回读实际值确认；旧固件仍可读取参数，启动页和朝向入口提示升级。Android 按设置项合并排队请求，连续修改不同项目不会相互覆盖，不抢占车辆或行程同步；失败有限重试后继续正常数据同步。
- 两端内置同一份 4.1.3 OTA 固件；保留原有历史固件回滚资源。Android 独立“等待仪表上电”通知开关、设置图标尺寸及既有数据迁移修复保持不变。
- 同步两端设置说明、当前版本与下载安装入口，保留 README 其他内容及 1.75-G 为未来 GPS／定位扩展预留硬件的推荐理由。

## 仪表固件 4.1.3

- 仪表自身设置页保留启动页面选择，新增四向朝向选择；再次进入设置页会读取手机更新后的保存值。
- 屏幕内容（包括启动画面）与触摸坐标按同一朝向转换。旋转完整刷新区域以保留屏幕对齐要求，复用既有第二块 DMA 缓冲，不增加原有显示 DMA 内存预算；0° 保留原显示路径。
- NVS 配置迁移至 v13：保留原先默认页及其他配置，旧版朝向初始化为 0°，避免升级后突然改变安装方向。启动页／朝向先成功写入闪存才更新回读值；失败保持旧值，重复相同请求不额外写闪存。
- 设置快照增加 v3（108 字节），在原字段后追加朝向；独立显示控制特征增加启动页和朝向命令，校验版本、长度、范围和 CRC。GATT 回调只排队，由 UI 任务保存，不在蓝牙回调中操作屏幕或闪存。
- 保留 GNSS 授时、四车型基础支持、低速有效车速、燃油与里程独立累计、既有行程和油耗数据；此次没有新增卫星位置或轨迹功能。

## OBD Studio 1.2～1.4 积累更新

- 适配 Windows 高 DPI 和笔记本可用屏幕尺寸，窗口支持缩至 640×420；左右面板独立滚动、分隔条可拖动，数据卡片自动切换两列／四列。停止按钮固定在底部；日志默认折叠，错误时自动展开。
- 新增与生产仪表对应的 14 槽轮询调度及 ZC6／ZD8、6MT／6AT 四车型选择，图形界面和命令行共用采集实现；保留旧 `Zd8Poll` 兼容入口。初始化、分频、支持位图探测、油量／燃油流量探测及查询上限按车型处理。
- 自动挡模式禁用挡位专用请求；新增 ZC6 `2101` 机油温度解析，接受完整 40／41 字节平铺或声明长度的分帧响应，拒绝截断和错序数据。其余标准车速、转速、水温、MAF、节气门、电压解码保持原有能力。仪表轮询的请求顺序对应固件，不宣称 Windows 调度具有相同实时性。
- 全量采集模式保留最后有效样本，不因年龄到期而清空卡片、响应或积分值；回放沿用相同模式，录制元数据记录模式。收到明确无效响应仍会清除该数据有效性；其他模式保留原有过期保护。
- 全量模式在慢采样间隔内按保持值估算里程和耗油，说明文档明确这不是连续实测；已有 JSONL 录制保持兼容。启动脚本、工具说明和版本标识更新至 1.4。

## 附件与升级

- `BRZ-Garage-v4.6.4-debug.apk` 与 SHA-256：沿用原 Android 签名，直接覆盖安装，勿先卸载；建议先导出备份。
- 更新 App 后，还需通过 App 单独升级仪表至 4.1.3，才能在手机上修改仪表默认启动页和朝向。普通升级保留 NVS 与历史数据；两项设置在下次上电生效。
- `BRZ-Garage-Flasher-v4.1.3-r4-Windows-x64.zip` 与 SHA-256：内置本次相同 4.1.3 镜像，解压运行 `Start-Flasher.cmd`；按工具流程先备份，不选择清空数据来执行普通升级。
- `obd_brz_gauge.bin`、SHA-256、`latest.json`、`validation.json`：对应 4.1.3；BIN 为应用分区镜像，不能作为整片镜像写入地址 0。
- `BRZ-OBD-Studio-v1.4.exe` 与 SHA-256：Windows x64 采集／回放工具，独立于一键烧录包。
- 鸿蒙公开交付 0.6.3 源码，不上传含设备授权信息的调试 HAP。迁移格式保持 v7，继续读取 v1～v6；两端旧 v7 备份仍兼容。

## 验证与限制

ESP-IDF 固件、Android APK、鸿蒙 ArkTS/HAP 和 OBD Studio 构建通过。启动配置持久化／失败重试／重启恢复、四向像素与触摸逆变换、旧协议兼容及 CRC 校验已通过宿主测试；鸿蒙 136 项测试和 Android↔鸿蒙数据往返通过。发布附件的版本、签名与 SHA-256、一键烧录包全部内置镜像以及两端内置 OTA 镜像一致性已核对，具体结果随 `validation.json` 提供。

尚未进行这次版本的手机安装、实际 BLE 写入／OTA、仪表四方向视觉与触摸手感、旋转性能、实车采集与自动挡路试、Windows 高 DPI 多设备体验或 G 版 GNSS 真机验收。源码与构建验证不代表全部设备验收完成。
