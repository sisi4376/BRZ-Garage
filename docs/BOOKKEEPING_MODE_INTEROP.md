# 精简版 / 精细版记账互通检查 — App 4.5.4

检查日期：2026-11-05。Android versionCode 164，数据包仍为 v6，SQLite 结构不变。

## 结论

两种界面共用 fuel_records 和 expenses，切换模式仅更新界面偏好与路由，不搬运、复制或重写账目。数据层互通测试通过，修复了影响切换体验的导航和表单问题。没有连接 Android 手机或模拟器，尚不能把这些结果当成真机触控、动画及视觉流畅性的验收。

## 发现与修复

1. 原先按下标截断栏目：精简日常 index 2 切精细后误到资产 index 2；统计也会落入其他栏目。现在按含义映射日常、统计；精细保险/年审/证件子页映射精简日常，保养映射保养。
2. 收入与资产子页此前没有切换入口；精简也没有完整资产历史入口。现在收入、资产与固定开销子页可直接切换模式，精简日常提供资产清单/完整历史入口；资产与收入的对应子页可双向继续查看。
3. 不同栏目/模式共用滚动缓存，可能错用旧位置。现在区分缓存，并在改变模式前保存原页面位置；年度、月份、固定开销子页、收支状态和统计返回位置随页面重建保存。
4. 精简新增日常记录选择保险时，原表单仍按默认普通支出创建，险种快捷入口及保障日期没有联动。现在选择保险即显示相关字段，切回普通类别恢复原日期字段；用户主动清除可选日期后不会强行补回。
5. 明确标为年审的旧记录及精简分类图没有独立映射。现在兼容无 ledger_kind 的“年审”标题，图中保留其独立分类。

## 数据对应关系

| 账目 | 精简版 | 精细版 |
|---|---|---|
| 加油 | 加油 | 加油 |
| 保养、维修 | 保养/维修 | 固定开销 → 保养/维修 |
| 保险、年审、证件手续 | 日常支出；附加信息保留 | 固定开销对应栏目 |
| 配件用品、车辆配件 | 原日常成本记录及资产详情入口 | 资产登记/持有/历史 |
| 停车、通行、洗护、违章、其他 | 日常支出 | 日常支出 |
| 他人付款、报销、出售等收入 | 收入记录 | 日常 → 收入 |
| 资产出售/移除/撤销 | 共用资产详情与完整历史 | 同一份资产事件 |

固定/资产分项的展示结构不同；两种模式的总支出、总收入和净支出必须一致。资产原记录不能直接覆盖，误录可“撤销并删除”后重录；出售/移除正常操作保留购买与处置历史。此规则在两种模式一致。
