# BRZ ZD8 挡位读取与回退策略

ZD8 6MT 使用两级策略，任何数据源停止更新后都不会让页面卡在旧挡位：

1. **标准 PID 01 A4**：先用 `01 A0` 支持位确认 A4 是否存在；车辆移动时读取 C、D 给出的实际传动比，并与 ZD8 齿比表匹配。只有连续两次落入同一挡位且误差不超过 8% 才会采用。
2. **RPM/车速推算**：A4 不存在或数值异常时启用。速度使用未经显示平滑的原始值。RPM 或车速任一到达时均尝试配对，时间差上限为 750 ms，以适应 ELM327/BLE 串行请求。每条样本最多参与一次配对，新挡位需要两组独立数据确认；缺少另一条样本时等待，不清空候选。已确认挡位最多保留 3 秒，候选两次确认之间最多间隔 3 秒；新鲜配对不符合齿比时立即显示 `--`。断连/切换车型清除未配对样本，防止旧数据串入新连接。

该时间窗口不是同一时刻的 ECU 快照，急加速和换挡仍可能暂时无法可靠推算。离合状态没有直接输入，`--` 不能等同于“已检测到踩离合”。

ZD8 脚部 OBD-II 接口经过网关，只开放诊断请求，通常不暴露 `0x241` 原始广播。因此普通 ELM327 模式不再进入 ATMA，避免每轮数百毫秒的采集停顿。只有未来改用 ASC/DCM 直连 CAN 收发器时，才应启用 `0x241`（bit 35..37，`0=N`、`1..6=前进挡`）。

## 车型选项

- `ZD8`：推荐的6MT脚部 OBD 模式，尝试 A4，否则同步推算。
- `ZD8 OBD`：兼容旧配置，采用相同的纯 OBD 数据路径。

## 真车验证

1. 选择 `ZD8`，在每个挡位稳定油门行驶 2 秒，依次验证 1 至 6 挡。
2. 换挡踩离合期间应短暂显示 `--`，接合后连续两个速度样本确认新挡位。
3. 速度低于 3 km/h 时沿用 `N` 显示约定，不代表确实检测到空挡（停车挂挡/踩离合也无法区分）；仅靠无方向的标准速度 PID 无法可靠区分倒挡与1挡。
4. ELM327 终端可用 `01 A0` 检查 A4 支持位，再在车辆移动时发送 `01 A4` 检查实际响应。

## 自动回归验证

`python -m unittest discover -s tests -p test_zd8_gear_strategy.py -v` 会通过主机编译器直接编译并执行固件的 `obd_data_cache.c`，覆盖 1–6 挡、0–750 ms 响应延迟、两种到达顺序、样本去重、换挡/不匹配、数据过期、重连清空和直接信号优先级。使用桩时钟和 ZD8 参数，不代表已完成实车验证。
