# OBD Studio Android

独立的 Android BLE OBD 数据采集、查看和仪表回放工具。Android 8.0+，包名 `com.brz.obdstudio`，可与 BRZ Garage 同时安装。当前版本 **1.0.0-beta.1**。

安装项目根目录的 `BRZ-OBD-Studio-Android-v1.0.0-beta.1.apk`。首次操作按系统提示授予蓝牙／附近设备权限；Android 11 及以下扫描还需要定位权限与系统定位开关。通知权限用于显示后台任务和停止入口。

## 与电脑版功能对应

| 电脑版功能 | Android 入口 |
|---|---|
| BLE 扫描、按地址连接 | 采集 → 扫描设备，或填写手动地址 |
| FFF0、18F0、FF12 适配器 | 按相同优先级自动选择写入／通知特征 |
| 四车型仪表轮询 | 采集范围前四项：ZD8/ZC6，6MT/6AT |
| 全量保留模式、常用 PID、旧 ZC6 精简模式 | 采集范围其余选项 |
| 额外只读请求、时长、请求间隔 | 采集页；仪表同款模式固定调度，不接受额外命令 |
| 转速、车速、水温、油温 | 实时页，含 ZC6 `2101` 完整多包油温解析 |
| 瞬时／平均油耗、里程、耗油、油量、总里程、电压 | 实时页，区分 ECU 数据与 MAF 汽油估算 |
| 原始请求／通知分包／完整响应 | JSONL 保留原始十六进制字节和单调时间戳；实时页显示每个请求最新响应与年龄 |
| 最近 60 秒转速曲线与日志 | 实时页及各页底部日志 |
| 保存 JSONL 和统计摘要 | 默认应用本地；选择自动导出文件夹后，停止时复制两份文件 |
| 导入、导出文件 | 文件页；导出原始 JSONL 或 `.summary.json` |
| 0.25～4 倍速、循环回放 | 回放页；支持导入电脑版 JSONL |
| 通过 BLE 回放到实体仪表 | 启动回放后，仪表 BLE SCAN 选择手机的 FFF0 服务 |
| 停止任务并保存 | 底部固定按钮，或前台服务通知的停止按钮 |

## 使用

1. 让其他 App 和仪表断开车上的 ELM327。开启手机蓝牙，在采集页扫描选择适配器，选择采集模式后点击“开始录制”。
2. 实时页查看数据。关闭界面或切到后台后任务继续；用应用或通知中的“停止并保存”结束。系统强行停止、应用被系统杀死或断电不保证写出最终摘要，但已经逐行刷新的 JSONL 仍保留此前数据。
3. 文件默认保存在应用私有目录；需要拷到电脑时在文件页导出。也可在采集前选择自动导出文件夹，停止后自动复制原始录制和摘要。卸载前先导出需要保留的文件。
4. 回放时选择本地或导入的 JSONL，设置速度和循环，然后启动。在仪表扫描页选择这台手机，等待仪表实时请求。手机蓝牙名称过长时广播可能只显示地址或未知设备，请结合 FFF0 服务辨认。

录制使用与电脑版相同的 schema 1。手机、电脑可以相互回放；旧文件没有统计摘要也能导入。文件末尾因中断留下的不完整行在加载时忽略，其余格式损坏会报错。原始文件导出保持内容不变。回放时间轴从第一次实时请求开始，每个仪表独立计时；ATZ 不重启时间轴，断线重连从头开始。未知请求、不同 ECU 请求地址和 ATH1 请求返回 NO DATA，不注入静态假数据。回放采用 20 字节通知分包并等待每次通知完成。

全量模式没有总录制时长或样本年龄限制，保留最近采样值；累计里程和耗油按该值保持到下一份响应，属于采样间隔估算。其他模式统计样本有效期为 5 秒，卡片超过 15 秒未更新显示空值。平均油耗至少需要 10 米共同有效里程。燃油优先使用 `015E`，否则使用转速、MAF、指令 λ 和汽油密度 745 g/L 的估算，与电脑版一致；未完整模拟固件的车型减速断油和挡位推断。

所有采集命令顺序等待 `>`，查询超时后保存并停止，防止迟到响应错配。全量指 ECU 声明支持的标准实时 PID 以及实际收到的 ELM 数据，不代表整车 CAN 总线全部报文。不支持经典蓝牙 SPP、Wi-Fi ELM 或被动 CAN 监听。

蓝牙回放要求手机支持 BLE 外设广播，系统或硬件不支持时会显示错误。前台服务维持后台任务，不代表能绕过厂商省电策略；设备端的扫描、熄屏采集、广播、订阅与实际仪表显示仍需实机验证。

## 验证与构建

已完成 APK 编译，以及 Android 生产 Kotlin 代码与电脑版的 4,072 项核心对照检查，覆盖四车型调度、统计、ZC6 油温、JSONL 双向读写、时间轴、倍速、循环、分包、请求边界和错误值。不应把这些检查当作已完成实车或手机测试。

在 `android_app` 工程运行 `:obd_studio:assembleDebug`，生成独立模块 APK；采用项目现有本地调试签名。测试运行 `python -m unittest discover -s tests -p test_obd_studio_android.py`，需要项目 Kotlin/JDK 和 `.toolchains/obd-studio-test/json-20250517.jar` 测试运行库。
